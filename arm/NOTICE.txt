GLUON-2L6-4L3 robot model
-------------------------
The URDF (src/arm/gluon.urdf, bundled with the viewer) and the meshes in ./meshes/ originate from the
"gluon" ROS description package
published by Mintasca:

  https://github.com/mintasca/ros_gluon  (gluon/package.xml: license BSD)

Meshes were converted from STL to GLB and decimated for web delivery;
geometry is otherwise unmodified.

Kinematics are original C11 (src/arm/c/kinematics.c, compiled into
./viewer/arm.wasm) with a JavaScript reference (src/arm/kinematics.js), both
ported from the author's MIT-licensed clean-room Rust library
gluon-kinematics; see the git history before its removal, tag
gluon-rust-final.
